# Модуль «Loyalty Pro»

**2 990 ₽/мес · 29 900 ₽/год** · ключ `loyalty_pro` · категория `crm` · подключается в `/admin → Тарифы → Подключаемые модули`.

Полноценная программа лояльности: тиры, акции, начисление и обмен баллов, реферальные бонусы, кэшбэк. Базовые бонусы за направления (`Bonus`) есть бесплатно — этот модуль расширяет их в полноценную loyalty-программу для удержания пациентов.

## Что это даёт клинике

- Удержание пациентов: тиры повышают LTV (Bronze → Silver → Gold → Platinum).
- Привлечение через сарафан: реферальный бонус за приведённого друга.
- Возврат «спящих»: реактивация через начисление подарочных баллов.
- Аналитика: отчёты по эффективности правил начисления.

## Что входит сверх базовых бонусов

- **Тиры** (`LoyaltyTier`): Bronze / Silver / Gold / Platinum. Автоповышение по сумме платежей за период (порог настраивается). Каждый тир — свой % cashback и привилегии.
- **Транзакции** (`LoyaltyTransaction`): полная история начислений, списаний, корректировок. С expire_at для просрочки.
- **Правила** (`LoyaltyRule`): «при покупке услуги X начислить N% баллами», «в день рождения +500 баллов», «реферал +1000 за приведённого друга».
- **Награды** (`LoyaltyReward`): каталог обмена. «1000 баллов = 1500 ₽ на услугу терапевта». Можно ограничить категориями.
- **Реферальная программа**: уникальный код пациента → его друг при первой записи получает скидку, а пациент — баллы.
- **Расходование**: при оплате визита пациент может списать N% от чека баллами.

## Как настроить

1. Активировать модуль в `/admin → Тарифы → Подключаемые модули`.
2. `/admin/loyalty/tiers` — создать тиры с порогами (например: 0 / 10 000 / 50 000 / 200 000 ₽).
3. `/admin/loyalty/rules` — настроить правила начисления: базовый кэшбэк (3-5%), бонусы за ДР, рефералы.
4. `/admin/loyalty/rewards` — каталог обмена. Минимум 5-10 наград для старта.
5. Опубликовать программу в CMS-блоке: пациенты увидят свой тир и баллы в личном кабинете.

## Как пользоваться

### Со стороны пациента

- В личном кабинете блок «Лояльность»: текущий тир, баллы, прогресс до следующего тира.
- При записи на услугу — опция «применить баллы» (% от чека).
- Реферальный код — копируется одной кнопкой, шарится в мессенджеры.
- История транзакций — с фильтром «начисления / списания / истёкшие».

### Со стороны клиники

- `/admin/loyalty/transactions` — лог всех операций, поиск по пациенту.
- При оплате на ресепшене — автоматическое начисление по правилам.
- Ручное начисление (компенсация, акция): `/admin/loyalty/earn` форма с указанием причины.

## API endpoints

- `GET /loyalty/account/{phone}` — баланс пациента.
- `GET /loyalty/transactions/{phone}` — история операций.
- `POST /loyalty/earn` — начислить баллы.
- `POST /loyalty/redeem` — списать.
- `POST /loyalty/exchange` — обменять баллы на награду.
- `GET /loyalty/tiers` / `POST /loyalty/tiers` / `PATCH` / `DELETE` — управление тирами.
- `GET /loyalty/rules` / `POST` / `PATCH` / `DELETE` — правила начисления.
- `GET /loyalty/rewards` / `POST` / `PATCH` / `DELETE` — каталог наград.
- `GET /loyalty/tiers/with-top` — тиры со списком top-пациентов.

Patient API:
- `GET /patient/loyalty/account` — мой баланс и тир.
- `GET /patient/loyalty/transactions` — моя история.

## Известные ограничения

- Срок жизни баллов — настраивается, но один на всю программу (нельзя задать разный TTL по правилам).
- Бонусы за направления (`Bonus`) — отдельная сущность, не пересекается с `LoyaltyTransaction`.
- Реферальный код не работает кросс-тенант (только в рамках одной сети клиник).

## Метрики и аналитика

В `/admin/loyalty/analytics`:
- Распределение пациентов по тирам (% Bronze / Silver / Gold / Platinum).
- Топ-10 пациентов по балансу баллов.
- Доля выручки, оплаченной баллами (за период).
- Средний чек по тирам (Platinum обычно в 3-5 раз выше Bronze).
- Конверсия реферальных кодов (отправлено → активировано).
- Cohort retention: пациенты, вступившие в тир X в месяце Y, остались в нём через 90 дней.

## Best practices

1. Не делать порог Platinum слишком высоким — пациенты должны видеть достижимость.
2. Базовый кэшбэк 3-5% — экономика выдержит, ниже — пациент не замечает.
3. Реферал = «друг получает скидку 1000 ₽, вы — 1000 баллов» — двусторонняя выгода.
4. ДР-бонус 500-1000 баллов — недорого, но запоминается.
5. TTL баллов 12 мес — мотивирует на возврат, не «копит навсегда».

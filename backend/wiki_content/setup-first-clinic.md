# Запуск первой клиники

## Кому это руководство

Эта статья — для **владельца франшизы**, который только что получил доступ к платформе и хочет запустить первую клинику в своей сети. Для приглашения сотрудников см. [Создание сотрудников](/wiki/setup-staff).

Стандартный путь от регистрации до приёма первого пациента занимает 2–4 часа сосредоточенной работы.

## Шаг 1: первичная настройка кабинета

После активации тенанта (зашёл по invite от платформы) ты попадаешь в `FranchiseOwnerCabinet`.

1. Заполни «Профиль франшизы»: юридическое лицо, контакты, реквизиты.
2. Загрузи логотип (PNG или SVG, прозрачный фон).
3. Выбери основной цвет бренда (если хочешь white-label-ощущения сразу — подключи модуль).

Эти данные используются в письмах пациентам и в шапке кабинетов.

## Шаг 2: создание клиники

В разделе «Клиники» нажми «Новая клиника»:

- **Название** — отображается пациентам.
- **Адрес** — улица, дом, корпус, этаж.
- **Часовой пояс** — критично для расписания.
- **Контактный телефон** — для пациентов.
- **Тип медлицензии** — для отчётности.
- **Часы работы** — общие, можно потом скорректировать по дням недели.

После сохранения клиника появится в списке. Состояние — «Чёрный список / готовится».

## Шаг 3: услуги и цены

В карточке клиники → «Услуги»:

1. Добавь медицинские услуги (например, «Консультация терапевта», «УЗИ органов брюшной полости»).
2. Для каждой укажи: цена, длительность, специальность.
3. Можно загрузить готовый CSV с услугами (шаблон есть в интерфейсе).

> Внимание: длительность услуги влияет на расписание. Если у тебя слоты по 15 минут, а услуга 60 — она займёт 4 последовательных слота.

## Шаг 4: специальности и кабинеты

«Настройки клиники → Специальности» — выбери, какие направления у тебя есть (терапия, кардиология, УЗИ, лаборатория). От этого зависит фильтр в онлайн-записи пациентов.

«Кабинеты» — физические помещения. Каждый кабинет может быть привязан к одной или нескольким специальностям.

## Шаг 5: пригласи врачей

См. [Создание сотрудников](/wiki/setup-staff). Минимум для старта — 1 врач и 1 регистратор.

## Шаг 6: расписание

После приёма врача:

1. «Расписание» → выбери врача и неделю.
2. Применить готовый шаблон («Стандарт 5/2», «Сменный график») или вручную.
3. Сохрани — слоты сразу станут доступны для записи пациентов.

## Шаг 7: подключи модули (опционально)

Базового набора достаточно для первой клиники. Но рекомендуется на старте подумать о:

- **CMS лендинга** — чтобы у клиники сразу был сайт с описанием.
- **Поддержка-чат** — чтобы пациенты могли задать вопрос до записи.
- **AI-ассистент для пациента** — снижает нагрузку на регистратора.

См. [Каталог модулей](/wiki/concepts-modules).

## Шаг 8: тестовая запись

Перед открытием для пациентов сделай тестовую запись:

1. Зарегистрируйся в платформе как пациент (отдельный номер телефона).
2. Запишись на приём.
3. Пройди весь процесс: подтверждение, напоминание, визит, оплата.
4. Проверь, что всё работает.

Только после этого открывай ссылку на онлайн-запись для реальных пациентов.

## Шаг 9: маркетинг и привлечение

Опции для первого потока:

- **Публичная страница** — `/<slug>/clinic` доступна по умолчанию.
- **CMS лендинг** (если модуль подключен) — настрой, опубликуй.
- **Партнёры-врачи** — пригласи через рекрутера или сам в разделе «Партнёры».
- **Программа лояльности** — кешбэк 5–10% на следующий визит для первых клиентов.

## Шаг 10: мониторинг

Каждый день в первую неделю проверяй:

- Сколько записей создано.
- Сколько отменено / не пришли.
- Чат поддержки — нет ли проблем у пациентов.
- KPI врачей — успевают ли вести приёмы.

Через неделю — первый ретроспектив с управляющим клиники: что работает, что починить.

## Чеклист готовности

- [ ] Профиль франшизы заполнен
- [ ] Клиника создана, адрес и телефон указаны
- [ ] Услуги и цены загружены
- [ ] Управляющий приглашён
- [ ] Минимум 1 врач принят и расписание заполнено
- [ ] Минимум 1 регистратор приглашён
- [ ] Тестовая запись прошла успешно
- [ ] Канал записи (онлайн / телефон / партнёры) определён

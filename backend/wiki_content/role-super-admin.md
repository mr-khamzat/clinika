# Роль: Платформа · супер-админ

## Кто ты в системе

Супер-админ платформы КлиникСеть — высшая техническая и бизнес-роль. Через единую панель `/admin` ты управляешь всеми тенантами (франшизами клиник), общим биллингом, набором подключаемых модулей, мониторингом инфраструктуры и аудитом действий пользователей. В отличие от владельца франшизы, у тебя есть глобальная видимость и право выполнять системные операции — переключение подписок, ручную корректировку лимитов, разбор инцидентов.

Ключевая ответственность — стабильность и доступность платформы для всех клиентов. Любое действие супер-админа логируется в системный аудит-журнал и не может быть удалено.

## Что ты видишь

При входе по пути `/admin` открывается AdminRoot — глобальная панель платформы. Основные разделы:

- **Тенанты** — список франшиз: статус подписки, активные модули, владельцы, лимиты.
- **Биллинг** — общий ledger по платежам, инвойсы, дебетовая корзина, налоги.
- **Модули** — каталог подключаемых модулей и матрица доступа по тенантам.
- **Мониторинг** — статус сервисов, очередей, фоновых задач.
- **Аудит** — лог действий админов и владельцев франшиз.
- **Поддержка** — список открытых тикетов от клиник.
- **Настройки платформы** — глобальные параметры, ключи интеграций, темы.

## Что ты можешь делать

- **Создать нового тенанта (франшизу)**:
  1. Раздел «Тенанты» → кнопка «Новый тенант».
  2. Введи slug (поддомен), имя владельца, e-mail.
  3. Выбери стартовый тарифный план.
  4. Система создаст БД-секцию, отправит invite владельцу.
  5. Владелец проходит регистрацию и настраивает первую клинику.

- **Подключить модуль тенанту**:
  1. «Тенанты» → открой нужного.
  2. Вкладка «Модули» → переключи флаг.
  3. При активации модуля автоматически создаётся подписка `tenant_module_subscriptions`.
  4. Биллинг учитывает модуль в следующем инвойсе.

- **Заблокировать или приостановить тенанта**:
  1. Карточка тенанта → действие «Приостановить».
  2. Укажи причину (просрочка оплаты, нарушение и т.д.).
  3. Все пользователи тенанта увидят соответствующий экран при попытке входа.

- **Разобрать инцидент с биллингом**:
  1. «Биллинг» → найди операцию по ID или дате.
  2. Открой ledger-запись.
  3. При необходимости создай корректирующий entry.

- **Выполнить системную диагностику**:
  1. «Мониторинг» → проверь статус Redis, Postgres, фоновых очередей.
  2. При деградации — открой раздел логов.
  3. Эскалируй провайдеру инфраструктуры.

## Что ты НЕ можешь делать

- Изменять задним числом проведённые финансовые транзакции (только корректировки).
- Удалять системный аудит-журнал.
- Видеть содержимое медицинских протоколов пациентов клиник (только метаданные).
- Изменять данные пациентов (это право клиники).

> Внимание: любая операция супер-админа логируется. Удаление или подмена логов невозможны на уровне БД.

## Кто над тобой

Прямого подчинения нет — это роль владельца платформы или техлида. Над тобой только бизнес-стейкхолдеры (учредители платформы).

## Кто под тобой

- **Владельцы франшиз** — каждый управляет своей сетью клиник.
- **Управляющие клиник** — операционные руководители на местах.
- **Все остальные роли** — врачи, регистраторы, медсёстры, пациенты.

## FAQ для этой роли

**Как восстановить случайно удалённого тенанта?**
Тенанты не удаляются физически — только переходят в статус «Архив». Восстановление выполняется через смену статуса в карточке тенанта.

**Где посмотреть, кто из админов выполнил то или иное действие?**
Раздел «Аудит» → фильтр по дате, типу события и пользователю. Каждая запись содержит IP, user-agent и описание изменения.

**Как добавить новый модуль в каталог?**
Через миграцию БД (alembic) и фронт-конфиг каталога. См. внутреннюю документацию для разработчиков.

**Можно ли увидеть PII пациентов?**
Нет. Принцип zero-knowledge: супер-админ видит метаданные (количество пациентов, клиник, приёмов), но не персональные данные.

**Как настроить кастомный домен для франшизы (white-label)?**
Карточка тенанта → «Брендирование». См. модуль white-label в [Каталоге модулей](/wiki/concepts-modules).

**Что делать при просрочке оплаты тенантом?**
Биллинг автоматически выставляет напоминания. После 14 дней просрочки — авто-приостановка. Ручная разблокировка через карточку тенанта.

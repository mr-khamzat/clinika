# Модуль «Запись звонков + Whisper»

**3 990 ₽/мес · 43 092 ₽/год** · ключ `call_recording` · категория `telephony` · подключается в `/admin → Тарифы → Подключаемые модули`.

Автоматическая запись звонков (телефонных и видеоприёмов) с расшифровкой через OpenAI Whisper и AI-резюме приёма через Gemini. Десктоп-приложение KliniknetCalls (Electron) интегрировано с CRM для регистраторов и врачей.

## Что это даёт клинике

- Контроль качества обслуживания: владелец видит, как регистратор общается с пациентом.
- Разбор спорных ситуаций: «вы говорили, что приём в 14:00» — открыли запись, проверили.
- Сокращение времени на оформление протокола: Whisper делает 80% работы — врачу остаётся только проверить.
- Тренинг сотрудников: лучшие примеры диалогов в базу знаний.

## Что входит технически

- **Запись** (`CallRecording`) — все исходящие/входящие звонки регистратора + видеоприёмы. Аудио в S3-совместимом хранилище (minio / Selectel S3).
- **Транскрипция** (`CallTranscript`) — Whisper API: текст диалога с тайминговыми метками, распознавание говорящего (врач/пациент через diarization).
- **AI-резюме** через Gemini: ключевые жалобы, диагноз, рекомендации, упомянутые препараты. Сразу видно в карточке пациента.
- **Поиск по транскриптам** — найти все упоминания препарата/диагноза/симптома по всем приёмам.
- **Экспорт** — PDF протокола приёма с расшифровкой.
- **Десктоп-клиент** KliniknetCalls (Electron): WhatsApp в боковой панели, встроенный AWG VPN, NSIS installer для Windows.

## Юридическое требование

Перед началом записи пациенту воспроизводится автоматическое уведомление: «Внимание, ваш звонок может быть записан в целях контроля качества». Это требование 152-ФЗ.

В карточке пациента — флаг «Согласие на запись звонков». Без него запись не запускается. Хранение записей — только в РФ (Селектел / Yandex Cloud).

## Как настроить

1. Активировать модуль в `/admin → Тарифы → Подключаемые модули`.
2. В `tenant_module_subscriptions.config` задать S3 endpoint:
   - `s3_endpoint`, `s3_access_key`, `s3_secret_key`, `s3_bucket`.
3. В `.env` платформы — `OPENAI_API_KEY` (Whisper) + `GOOGLE_GEMINI_API_KEY` (резюме).
4. Срок хранения настраивается (по умолчанию 90 дней, потом холодное хранение или удаление).
5. Для десктопа: скачать `KliniknetCalls-Setup-<version>.exe` с `https://клиниксеть.рф/downloads/`, установить, ввести логин CRM.

## Как пользоваться

### Со стороны регистратора

1. Открыть KliniknetCalls. Все звонки автоматически логируются (`/calls/log`).
2. После звонка — запись и транскрипт появляются в карточке пациента (через 1-3 мин после завершения).
3. Поиск по логу: `/admin/calls/log` с фильтрами по дате/пациенту/длительности.
4. Экспорт CSV — `/admin/calls/log/export.csv`.

### Со стороны врача

1. После видеоприёма — открыть карточку, вкладка «Запись приёма».
2. Слушать аудио, читать транскрипт, видеть AI-резюме.
3. Кнопка «Скопировать в протокол» — резюме попадает в карточку.

## API endpoints

- `POST /call-recordings` — создать запись (метаданные).
- `POST /call-recordings/{id}/upload` — залить аудио.
- `POST /call-recordings/{id}/finalize` — запустить транскрипцию.
- `GET /call-recordings` — список.
- `GET /call-recordings/{id}` — детали.
- `GET /call-recordings/{id}/file` — стриминг аудио.
- `GET /call-recordings/{id}/transcript` — транскрипт.
- `DELETE /call-recordings/{id}` — удалить.
- `GET /call-recordings/search/transcripts?q=...` — full-text поиск.
- `GET /calls/log` — лог звонков (без записи).
- `GET /calls/stats` — статистика.
- `GET /calls/directory` — справочник контактов.

## Известные ограничения

- Whisper API — платный, ~$0.006/мин. Платит тенант через свой OPENAI_API_KEY.
- Diarization (распознавание говорящего) — не 100%, при шуме путает голоса.
- KliniknetCalls 1.0.16 — баг с WhatsApp прокси через BasicAuth (фикс в 1.0.17).
- Только Windows-клиент. macOS / Linux — в roadmap.

## Best practices

1. Информировать пациента в первой фразе («Звонок может быть записан...»).
2. Хранение записей — 90 дней по умолчанию, после — холодное хранение или удаление.
3. Метки приёма (диагноз, выводы) — извлекать через AI-резюме, не вручную.
4. Owner / manager раз в неделю слушает 5 случайных звонков для контроля качества.
5. Сравнивать AI-резюме с реальным протоколом — корректировать промпт при системных ошибках.

## Метрики

- Время от завершения звонка до готовой расшифровки: 1-3 мин.
- Точность Whisper для русского: ~95% на чистой записи, ~85% при шуме.
- Стоимость Whisper: $0.006/мин → ~1 ₽/мин по курсу.
- Стоимость Gemini для резюме: ~$0.001 за приём (короткий промпт).

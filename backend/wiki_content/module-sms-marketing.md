# Модуль «SMS-маркетинг»

**1 990 ₽/мес · 21 492 ₽/год** · ключ `sms_marketing` · категория `marketing` · подключается в `/admin → Тарифы → Подключаемые модули`.

Возвращайте «спящих» пациентов через массовые рассылки с шаблонами и аналитикой. Использует ваш SMS-провайдер (SMSC.ru, SMS.ru или собственный gateway). Поддерживает A/B-тесты, расписание и сегментацию по тирам лояльности.

## Что это даёт клинике

- Реактивация спящих пациентов: «вас давно не было, у нас новый врач X».
- Поздравления с ДР со скидкой → запись на профилактический осмотр.
- Уведомления об акциях: чек ROI = выручка / стоимость SMS.
- Снижение no-show: напоминание за 24 часа до приёма.

## Что входит технически

- **Шаблоны** (`SmsTemplate`) — реактивация, ДР, акция, осмотр, отмена приёма. С переменными `{name}`, `{date}`, `{doctor}`, `{discount}`.
- **Кампании** (`SmsCampaign`) — wizard в 3 шага: аудитория → шаблон → запуск/расписание.
- **Сегментация**: по последнему визиту (60/90/180 дней), по тиру лояльности, по полу, по возрасту, по специализации последнего приёма.
- **A/B-тест**: разные тексты на части аудитории, метрика — % перешедших по deeplink.
- **Расписание**: разовая отправка / еженедельная / по дням недели.
- **Аналитика**: % доставлено / % ошибок / % перешли по ссылке / выручка с кампании.
- **Стоп-листы**: пациенты, отказавшиеся от рассылок (по 152-ФЗ).
- **Биллинг**: cron `sms_campaign_dispatch` шлёт пачками, считает по реальной цене провайдера.

## Как настроить

1. Активировать модуль в `/admin → Тарифы → Подключаемые модули`.
2. `/admin/settings/integrations/sms` — выбрать провайдера (SMSC.ru / SMS.ru / custom). Ввести API-ключ.
3. Заполнить отправителя (имя отправителя SMS — должно быть зарегистрировано у провайдера).
4. Создать 5-10 базовых шаблонов в `/admin/sms-marketing/templates`.
5. Проверить отправку через тестовый номер (свой телефон) перед запуском боевой кампании.

## Как пользоваться

### Создание кампании

1. `/admin/sms-marketing/campaigns/new`.
2. Шаг 1 — выбрать аудиторию (фильтры выше). Видно превью: «будет отправлено N пациентам».
3. Шаг 2 — выбрать шаблон. Превью с подставленными значениями.
4. Шаг 3 — выбрать дату/время отправки. «Сразу» или «по расписанию».
5. Запустить. Cron `sms_campaign_dispatch` подхватывает каждые 5 минут.

### Аналитика

1. `/admin/sms-marketing/campaigns/{id}/analytics`.
2. Доставлено / ошибок / переходов / новых записей.
3. ROI: выручка пациентов из этой кампании / стоимость SMS.

## API endpoints

- `GET /sms-marketing/templates` — список шаблонов.
- `POST /sms-marketing/templates` — создать.
- `PATCH /sms-marketing/templates/{id}` — обновить.
- `DELETE /sms-marketing/templates/{id}` — удалить.
- `GET /sms-marketing/campaigns` — список кампаний.
- `POST /sms-marketing/campaigns` — создать.
- `POST /sms-marketing/campaigns/{id}/start` — запустить.
- `POST /sms-marketing/campaigns/{id}/pause` — остановить.
- `GET /sms-marketing/campaigns/{id}/analytics` — статистика.
- `GET /sms-marketing/opt-outs` — стоп-лист.

## Известные ограничения

- Только SMS. Push-нотификации — отдельный канал (бесплатный, через `push.py` + Web Push).
- Telegram-уведомления — через `notify` plugin, отдельная настройка.
- Цена SMS в РФ — от 1.5 ₽/штука. Кампания на 1000 пациентов = ~1 500 ₽.
- Нет drag-and-drop редактора аудитории. Только фильтры.
- Стоп-лист хранится 5 лет (по 152-ФЗ).

## Best practices

1. Не больше 1 рассылки в 2 недели — пациент попадёт в стоп-лист.
2. Текст до 70 символов — 1 SMS-сегмент (дешевле).
3. Тестовая отправка на 50-100 пациентов → проверить деливерабилити → массовая.
4. Дип-линки `https://клиниксеть.рф/booking?promo=XYZ` — для трекинга.
5. День+время отправки — будний день 11:00-13:00 (открываемость выше).
6. A/B-тест двух текстов на 5% аудитории → выбрать лучший → разослать остатку.

## Метрики

- **Доставлено**: ~95% (если номера актуальные).
- **Переходов**: 5-15% (зависит от текста и аудитории).
- **Записи на приём**: 1-5% от рассылки.
- **ROI**: средний чек × % записей × кол-во отправок / стоимость SMS. Для типовой клиники 5-20x.

# Медкарта пациента и Timeline

Медицинская карта пациента в КлиникСеть состоит из трёх уровней, два из которых уже реализованы.

## Уровень 1 — Автоматическая хронология ✅

Вкладка **«Карта»** в ЛК пациента показывает **timeline** всех медицинских событий пациента, агрегированных из трёх источников:

### Источники данных
- **Подтверждённые направления** (`Referral.status=confirmed`) — со ссылкой на услугу/врача/анализы и клинику назначения
- **Завершённые приёмы** (`Appointment.status=completed`) — с ценой, способом оплаты, заметками врача
- **МИС-визиты Renovatio** — через `getAppointments` по всем клиникам тенанта с фильтром по `patient_id` из МИС

### Endpoint
`GET /patient/medcard/timeline?days=365&t=<session_token>`

Возвращает items с полями `type`, `date`, `title`, `subtitle`, `icon`, `category`, `referral_id`/`appointment_id`/`mis_appointment_id`, `price`, `payment_method`.

### Отображение
В UI каждое событие — карточка с цветной иконкой:
- 🔵 Синие — направления (`referral`)
- 🟢 Зелёные — приёмы (`appointment`)
- 🟣 Фиолетовые — МИС-визиты (`mis_visit`)

Сортировка — новые сверху. Лимит 200 events за период.

## Уровень 2 — Структурированный профиль 📋

В работе:
- **Диагнозы** (`patient_diagnoses`) — извлекаются из comments приёмов МИС или вводятся врачом
- **Аллергии** (`patient_allergies`) — отдельный тип записи с severity
- **Хронические заболевания** — длительные диагнозы с pin/unpin
- **Семейная история**
- **Прививки** (`patient_vaccinations`)

Эндпоинты:
- `GET /patient/medcard/diagnoses`
- `GET /patient/medcard/allergies`
- `GET /patient/medcard/vaccinations`

## Уровень 3 — AI-summary 🔮

В планах:
- LLM (Claude) строит «карточку пациента» из всех приёмов
- Doctor видит саммари перед приёмом: «У этого пациента: гипертония (с 2024), регулярные приёмы у кардиолога, последний ОАК 2026-04-15, ИМТ норма»
- Patient видит понятную картину

## Показатели здоровья

Отдельная вкладка **«Показатели»** с интеграциями:
- **Apple Health** (платный модуль `health_apple`) — через iOS-приложение
- **Google Fit** (платный модуль `health_google`) — через Android-приложение
- **Ручной ввод** — всегда доступен

Метрики: пульс, давление, SpO₂, температура, глюкоза, шаги, вес, рост, сон, HRV.

KPI-карточки динамически показывают **все метрики с данными** + графики за 30 дней.

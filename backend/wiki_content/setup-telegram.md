# Настройка Telegram-уведомлений

## Когда нужна

Telegram — бесплатный и быстрый канал для:

- Уведомлений о новых направлениях / приёмах
- Алертов о просрочке платежа
- Системных алертов (disaster mode, security)
- Двусторонней связи с пациентом через бот

В отличие от SMS, Telegram не требует оплаты провайдеру и доставляется мгновенно.

## Архитектура

```
Пользователь привязывает Telegram → платформа знает chat_id
                                    │
                                    ▼
Событие в платформе → bot отправляет сообщение в chat_id
```

Один бот платформы обслуживает всех пользователей. Для white-label франшиз — отдельный бот на свой бренд (модуль).

## Что подготовить

1. Аккаунт Telegram у владельца платформы (для создания бота).
2. Имя для бота (например, `@clinikset_bot`).

## Шаги настройки

### 1. Создание бота

1. Открыть Telegram, найти `@BotFather`.
2. Команда `/newbot`.
3. Имя: «КлиникСеть» (показывается пользователям).
4. Username: `@clinikset_bot` (уникальный, заканчивается на _bot).
5. BotFather присылает API token: `1234567890:AAEa...XYZ`. Сохраните.

### 2. Настройка бота (BotFather)

```
/setdescription — короткое описание бота
/setabouttext — текст в карточке профиля
/setuserpic — аватар бота
/setcommands — команды:
  start - Начало работы
  link - Привязать аккаунт
  help - Помощь
  notifications - Управление уведомлениями
```

### 3. Webhook

В кабинете super_admin → **Система → Telegram**:

```yaml
provider: telegram
bot_token: 1234567890:AAEa...XYZ
webhook_url: https://клиниксеть.рф/api/integrations/telegram/webhook
webhook_secret: <generated>
```

Платформа автоматически вызывает `setWebhook` у Telegram API:

```bash
curl -F "url=https://клиниксеть.рф/api/integrations/telegram/webhook" \
     -F "secret_token=<webhook_secret>" \
     https://api.telegram.org/bot<token>/setWebhook
```

### 4. Привязка пользователя

Пользователь (любой роли):

1. Открывает бота `@clinikset_bot`.
2. Команда `/start <token>` (токен — из кабинета).
3. Бот подтверждает: «Аккаунт привязан, теперь вы будете получать уведомления».

Или короткий путь — пользователь нажимает в кабинете кнопку «Привязать Telegram», открывается deep-link `tg://resolve?domain=clinikset_bot&start=<token>`.

## Типы уведомлений

| Событие | Кому | По умолчанию |
|---|---|---|
| Новое направление | reg, manager | ВКЛ |
| Подтверждение направления | manager | ВКЛ |
| Приём через 1 час | пациент, врач | ВКЛ |
| Приём отменён | manager, пациент | ВКЛ |
| Платёж получен | manager | ВКЛ |
| Платёж не прошёл | manager, owner | ВКЛ |
| Daily digest 09:00 МСК | manager, owner | ВКЛ |
| Disaster mode | super_admin, owner | ВКЛ |
| Security alert | super_admin | ВКЛ |
| Новое сообщение в чате | врач, пациент | ВКЛ |

Управление: в кабинете пользователя → **Настройки → Уведомления → Telegram**.

## Telegram бот команды

| Команда | Описание |
|---|---|
| `/start` | Приветствие, привязка |
| `/help` | Список команд |
| `/notifications` | Управление подписками |
| `/today` | Что у меня сегодня (приёмы) |
| `/balance` | Баланс (для врачей-партнёров) |
| `/unlink` | Отвязать аккаунт |

## Двусторонний чат

Если у тенанта подключен модуль `chat_telegram_relay`:

1. Пациент пишет в бот.
2. Бот пересылает сообщение в `patient_chat_thread` врача.
3. Врач отвечает в кабинете.
4. Ответ доставляется пациенту через бот.

Лимит — 1 поток на пациента.

## Лимиты Telegram API

| Параметр | Значение |
|---|---|
| Сообщений в секунду на чат | 1 |
| Сообщений в секунду глобально | 30 |
| Размер сообщения | 4096 символов |
| Размер фото | 10 MB |
| Размер файла | 50 MB |

Платформа автоматически держит очередь и не превышает лимиты.

## Безопасность

- Webhook от Telegram проверяется по заголовку `X-Telegram-Bot-Api-Secret-Token`.
- chat_id привязывается к user_id одноразовым токеном (TTL 15 минут).
- Если бот заблокирован пользователем — флаг `telegram_blocked=true`, попыток отправки нет.

## White-label вариант

Для франшиз, которые не хотят упоминать «КлиникСеть»:

1. Активируйте модуль `telegram_white_label`.
2. Создайте свой бот (`@familyclinic_bot`).
3. Введите его token в кабинет franchise_owner → Брендирование.
4. Все уведомления тенанта пойдут с вашего бота.

## FAQ

**Бот не отвечает на /start.** Проверьте webhook через `getWebhookInfo` Telegram API. Если ошибка — TLS-сертификат или URL.

**Уведомления приходят с задержкой.** Telegram гарантирует доставку за ≤1 секунду. Если задержка → проверьте очередь в `/admin/system/notifications/queue`.

**Можно ли отправлять файлы?** Да, через `sendDocument`. Используется для расходника, выписок.

**Пациент пожаловался — бот спамит.** Откройте `/admin/users/{id}/notifications`, отключите ненужные. Также пациент может сам через `/notifications` в боте.

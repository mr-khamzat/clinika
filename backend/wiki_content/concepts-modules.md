# Каталог платных модулей

## Зачем нужны модули

Базовая подписка КлиникСеть включает запись пациентов, ведение карт, расписание, документооборот, бонусы. Но многим клиникам нужны дополнительные возможности — видеоприём, AI-ассистент, интеграция с собственным сайтом или с лабораторной системой. Эти возможности оформлены как **платные модули**, которые франшиза подключает по необходимости.

Каждый модуль:

- Имеет свою стоимость (фиксированная плата или per-usage).
- Подключается на уровне франшизы (распространяется на все её клиники).
- Хранится в БД в таблице `tenant_module_subscriptions`.
- Может быть отключён в любой момент.

## Список модулей

### Видеозвонки (WebRTC)

Полноценный видеоприём через защищённый канал. Использует coturn-сервер, HMAC-SHA1 авторизацию, временные ICE-конфиги через `/presence/ice-config`. Шифрование E2E внутри клиники.

- **Кому**: клиникам с амбулаторными приёмами, психологам, диетологам.
- **Стоимость**: фикс. месячная плата за активного врача.
- **Активация**: после подключения у врачей в карточке записи появляется кнопка «Видеозвонок».

### AI-ассистент для пациента

Чат с LLM для предварительной оценки симптомов до записи. AI задаёт уточняющие вопросы, сужает диагнозы, рекомендует специальность. Не ставит диагноз — только направляет.

- **Кому**: клиникам с большим потоком первичных обращений.
- **Стоимость**: за 1000 диалогов.
- **Активация**: в кабинете пациента появляется вкладка «AI-чат».

### AI-протокол для врача

Помощник врача при заполнении протокола приёма. Распознаёт диктовку, структурирует текст, предлагает диагнозы из МКБ-10 на основе анамнеза.

- **Кому**: клиникам с большим потоком приёмов, где экономия 5 минут на приём = существенный эффект.
- **Стоимость**: за активного врача.
- **Активация**: кнопка «AI» внутри редактора протокола.

### MIS-интеграция

Двусторонняя интеграция с медицинской информационной системой клиники (1С-Медицина, ЭМК, лабораторные системы). Автоматический экспорт приёмов и импорт результатов анализов.

- **Кому**: крупным клиникам с уже работающим MIS.
- **Стоимость**: фикс. ежемесячная + интеграционный сбор.
- **Активация**: настройка через техподдержку платформы.

### White-label

Кастомный домен (например, `записаться.клиника-х.рф`), собственный логотип, цветовая палитра, фавикон во всех кабинетах. Письма пациентам уходят с домена клиники.

- **Кому**: премиальным клиникам и сетям, которые не хотят светить «КлиникСеть» перед пациентами.
- **Стоимость**: фикс. ежемесячная + единоразовый сбор за подключение домена.
- **Активация**: загрузка SSL-сертификата, настройка DNS, кастомизация в админке.

### Поддержка-чат (Support Chat)

Встроенный чат пациент ↔ клиника (а внутри клиники — между сотрудниками). С историей, прикреплением документов, индикаторами прочтения.

- **Кому**: клиникам, ориентированным на длительное сопровождение пациентов (стоматология, репродуктивная медицина).
- **Стоимость**: фикс. ежемесячная.
- **Активация**: появляется виджет чата в кабинетах.

### CMS для лендинга клиники

Конструктор страницы клиники: тексты, фото врачей, отзывы, услуги. SEO-оптимизация. Интегрирован с онлайн-записью.

- **Кому**: всем клиникам, которым нужна публичная веб-витрина.
- **Стоимость**: фикс. ежемесячная.
- **Активация**: появляется раздел «Сайт клиники» в кабинете управляющего.

### Программа лояльности (кешбэк)

Автоматический возврат пациенту процента от стоимости приёма в виде бонусов на следующие визиты. Гибкая настройка: разные ставки по услугам, исключения, ограничения.

- **Кому**: клиникам, конкурирующим за повторных пациентов.
- **Стоимость**: фикс. ежемесячная.
- **Активация**: настройки → «Программа лояльности».

### Электронные подписи врачей

Криптографическая подпись протоколов и направлений по ГОСТ Р 34.10. Юридически значимые документы для страховых компаний, ВВК, судов.

- **Кому**: клиникам, работающим со страховыми и государственными медкомиссиями.
- **Стоимость**: фикс. ежемесячная + стоимость токенов.
- **Активация**: после установки криптопровайдера и привязки сертификатов.

### Аналитика премиум

Расширенные drill-down дашборды, прогнозирование потоков, когортный анализ, A/B-тестирование. Экспорт в Power BI / Tableau.

- **Кому**: сетям клиник с собственным BI-отделом.
- **Стоимость**: фикс. ежемесячная.

## Кто подключает модули

Подключение и отключение — право **владельца франшизы**. Управляющий клиники может только запросить через внутреннюю заявку.

Процесс подключения:

1. Владелец заходит в свой кабинет → «Модули».
2. Видит каталог с ценами.
3. Нажимает «Подключить».
4. Подтверждает оплату (списание с баланса или сразу со счёта).
5. Модуль активируется в течение минуты.

## Что происходит при отключении

При отключении модуля:

- Связанные функции в UI скрываются.
- Данные сохраняются в read-only режиме (например, история видеоприёмов остаётся доступной для просмотра).
- При повторном подключении — всё восстанавливается.

> Внимание: некоторые модули (например, white-label с собственным доменом) требуют дополнительного времени на отключение — DNS должен «откатиться».

# components [05] — лендинг-секции, юр-страницы и таблица анализов

Срез охватывает 15 фронтенд-компонентов React (JSX) из трёх групп `frontend/src/components/`:

1. **`landing/` (13 файлов)** — презентационные секции публичного маркетингового лендинга «КлиникСеть» (`клиниксеть.рф/`). Это **витрина продукта, а не функционал МИС**: статический контент захардкожен прямо в компонентах (массивы `ROWS`, `QUESTIONS`, `ITEMS`, `METRICS`, `STEPS`, `SCENES`). Бэкенда почти не касаются — единственное сетевое обращение во всём срезе у `CtaNewsletter` (POST на `/contact/`). Стилизация двойная: одни компоненты используют inline-`style` + локальный `<style>{...}`-блок, другие опираются на глобальные CSS-классы `ks-*`, значительная часть которых живёт в `landing_extras.css.js` и подключается строкой в `Landing.jsx`.
2. **`legal/` (1 файл)** — общий layout-обёртка для юридических страниц (`/privacy`, `/terms`, `/consent`).
3. **`lab/` (1 файл)** — `LabResultsTable`, единственный «рабочий» компонент МИС в срезе: таблица результатов анализов, встраиваемая в кабинеты врача и пациента.

Общая визуальная ДНК лендинга: фирменный градиент `linear-gradient(135deg, #0097A7 0%, #1565C0 100%)` (бирюза→синий), карточки на `#fff` с `border: 1px solid var(--border)`, появление по скроллу через `IntersectionObserver` (паттерн повторяется в 5 файлах почти дословно — кандидат на вынос в общий хук).

- **Зависимости:** нет импортов вообще — самодостаточный, на inline-стилях. Связь с системой через props: `results` приходит из родительских секций (вероятно из API заказов лаборатории).
- **Где менять для типовых задач:**
  - Добавить/переименовать колонку — правь `<thead>` (строки 33-40) и соответствующую `<td>` в `.map` (строки 53-86).
  - Изменить логику «отклонения от нормы» — флаг `flagged` (строка 44); цвет строки/значения завязан на нём (`#fef2f2` фон, `#b91c1c` текст).

- **Подводные камни:** `value` выводится как есть (`r.value ?? '—'`) — никакого форматирования Decimal/float, бэкенд должен присылать готовую строку/число. `key` строки = `r.id || r.test_code || i` (индекс как последний фоллбэк — при динамической сортировке возможны артефакты React). Tenant-фильтрации тут нет: это чистая вьюшка, изоляция данных — ответственность вызывающей секции.

## `frontend/src/components/landing/CtaNewsletter.jsx`
- **Назначение:** Финальный call-to-action лендинга (`id="start"`): кнопки регистрации + форма подписки на email-дайджест. **Единственный компонент среза, реально стучащийся в API.**
- **Ключевые элементы:** default-экспорт `CtaNewsletter()`. Состояния: `email`, `website` (honeypot), `sent`, `loading`. Хэндлер `submit` шлёт `axios.post(API_BASE + '/contact/', {...})` с `name:'Newsletter'` и `message:'Подписка на дайджест...'`. При ошибке сети — graceful degradation: сохраняет email в `localStorage` (`ks_newsletter_email`) и всё равно показывает «Спасибо».
- **Эндпоинты:** компонент не роутер, но является **клиентом** эндпоинта:

| Метод | Путь | Доступ | Принимает | Возвращает | Назначение |
|-------|------|--------|-----------|------------|------------|
| POST | `{API_BASE}/contact/` | публичный | `{ name, email, phone, message, website_url }` | (ответ игнорируется) | Заявка/подписка с лендинга; `website_url` — honeypot для отсева ботов |

- **Зависимости:** `react` (`useState`), `axios`, `API_BASE` из `../../config` (резолвится в `/api`). Глобальные ks-классы (`ks-cta*`, см. `landing_extras.css.js`).
- **Где менять для типовых задач:**
  - Сменить эндпоинт/payload подписки — хэндлер `submit` (строки 20-38).
  - Добавить поля формы — внутри `<form onSubmit={submit}>` (строки 59-91) + соответствующее состояние.
  - Текст/кнопки CTA — JSX строки 45-57; trust-row строки 92-96.
- **Подводные камни:** honeypot-поле `website_url` отсекается **на бэке** (комментарий обещает 403) — скрыто CSS-офсетом `left:-9999px`, не `display:none` (чтобы боты заполнили). `submit` всегда ставит `sent=true` даже при ошибке — пользователь не видит сбоя, но и не узнаёт, что заявка не ушла (данные осели в localStorage). `async/await` без отдельной обработки сетевых статусов: `catch` ловит любую ошибку axios одинаково.
- **Строк:** 101

## `frontend/src/components/landing/NumbersStrip.jsx`
- **Назначение:** Лента из 4 ключевых метрик с анимацией count-up (числа «накручиваются» от 0 при появлении в viewport).
- **Ключевые элементы:** default-экспорт `NumbersStrip()`. Конфиг `METRICS` (4 объекта `{ value, suffix, title, subtitle }`). Под-компонент `CountUp({ target, suffix, run })` — анимация через `requestAnimationFrame` с ease-out-cubic, автоматически определяет число знаков после запятой (`Number.isInteger(target) ? 0 : 1`). Запуск завязан на `IntersectionObserver` (`threshold: 0.25`).
- **Зависимости:** `react` (`useEffect`, `useRef`, `useState`). Использует `performance.now()` и `requestAnimationFrame`. Градиентный текст через `WebkitBackgroundClip`.
- **Где менять для типовых задач:**
  - Метрики — массив `METRICS` (строки 8-13). Для дробных значений (`3.5`, `99.9`) count-up сам покажет 1 знак.
  - Скорость анимации — `duration = 1400` в `CountUp` (строка 23).

# КлиникаСеть — SaaS-платформа для медицинских сетей

> Готовая платформа для автоматизации направлений пациентов, бонусной системы, расписания врачей, МИС-интеграции, аналитики и взаиморасчётов. Мультитенантная SaaS-архитектура — каждая клиника получает изолированное пространство.

**Стек**: FastAPI 0.115 · SQLAlchemy 2.0 async · PostgreSQL 16 · Redis 7 · React 18 · Vite · Tailwind CSS · Docker Compose · Alembic

---

## Что умеет платформа

### Направления пациентов
- Цифровые QR-направления — создаются за 30 секунд
- Сканирование QR при визите → автоматическое подтверждение
- История всех направлений с фильтрами и экспортом
- Интеграция с МИС: визит подтверждается автоматически

### Бонусная система
- Начисление бонусов в момент подтверждения визита МИС
- Настраиваемые ставки: % от суммы или фиксированная сумма
- Выплата и списание с финансовым реестром
- История операций для каждого участника цепочки

### Интеграция с МИС (Renovatio и другие)
- Per-tenant настройка URL + API-ключ через панель управления
- Синхронизация врачей и клиник
- Автоподтверждение визитов через API
- Поддержка нескольких МИС для разных тенантов

### Расписание врачей
- Шаблоны рабочих дней по дням недели
- Онлайн-запись пациентов с проверкой конфликтов
- Статусы записей: pending / confirmed / cancelled / completed / no_show
- Доступные слоты с автоматической блокировкой занятых

### Аналитика и KPI
- Воронка направлений в 4 шага с конверсией
- Динамика по дням / неделям / месяцам
- Топ сотрудников и рейтинг клиник
- KPI и цели для каждого сотрудника
- Накопительный баланс (enterprise)

### Финансовый реестр (Ledger)
- Append-only журнал всех финансовых операций
- Типы: BONUS_ACCRUED / BONUS_PAID / MANUAL_CREDIT / MANUAL_DEBIT
- Баланс, pending-сумма, история — отдельно для каждого пользователя

### Аудит-лог
- 19 типов событий: USER_CREATED, BONUS_PAID, SETTINGS_UPDATED и др.
- JSONB before/after для каждого изменения
- Хранение IP и User-Agent

### Биллинг и тарифы

| Тариф | Ежемесячно | Годовой |
|---|---|---|
| Базовый | 9 900 руб/мес | 99 000 руб/год |
| Профессиональный | 24 900 руб/мес | 249 000 руб/год |
| Корпоративный | 49 900 руб/мес | 499 000 руб/год |

- Подписки со статусами: trial / active / past_due / paused / cancelled
- Счета: draft / sent / paid / overdue / void
- Пробный период 14 дней на всех тарифах

### Мониторинг
- Health-check эндпоинт (DB / Redis / MIS)
- Метрики запросов: p50 / p95 / p99, error_rate, top_endpoints
- История снимков здоровья системы (до 144 точек = 24ч)

### Безопасность (152-ФЗ)
- RBAC: manager / admin / partner / super_admin
- Refresh-токены с историей сессий и удалённым logout
- Согласия на обработку ПД: consent_given, consent_version
- Анонимизация пользователя по запросу (/consent/forget)
- Tenant isolation: все запросы фильтруются по tenant_id

### Уведомления
- SMS через smsc.ru / sms.ru (per-tenant настройка)
- Telegram-бот поддержки — per-tenant токен и чат
- Вебхуки (Webhooks): referral_created, bonus_paid, invoice_paid
- HMAC-SHA256 подпись каждого вебхука

### White-label и мультитенант
- Каждый тенант на своём slug: /{slug}/admin
- Кастомный брендинг: цвет, логотип, название через API
- Super admin: создание/управление тенантами, смена тарифа, сброс пароля

## Архитектура

```
nginx (reverse proxy)
  HTTPS -> /{slug}/api (backend), /{slug}/ (SPA)

clinika-frontend  (React 18 + Vite, port 8901)
clinika-backend   (FastAPI + Uvicorn, port 8900)
clinika-db        (PostgreSQL 16, port 5432)
clinika-redis     (Redis 7, port 6379)
```

### Мультитенантность
- Каждый тенант — изолированное пространство: tenant_id FK во всех таблицах
- Настройки (МИС, Telegram, брендинг) хранятся с префиксом {tenant_id}:{key}
- get_current_tenant() определяет тенант из JWT-токена (поле tid)
- require_feature() проверяет доступность фичи для плана тенанта

## Быстрый старт

```bash
git clone https://github.com/your-org/clinika.git
cd clinika

cp backend/.env.example backend/.env
# Заполнить: DATABASE_URL, SECRET_KEY, MIS_API_KEY, ...

docker compose up -d
docker exec clinika-backend alembic upgrade head
docker exec clinika-backend python seed.py
```

Доступ:
- Frontend: http://localhost:8901
- API docs: http://localhost:8900/docs
- Super admin: superadmin / superadmin2026

## 🚨 ЖДЁТ ТЕБЯ

Эти 6 действий не могу сделать без тебя. После них Этап 2 ROADMAP закроется:

### 1. SSH ключ — для блокировки пароля
```bash
# На своей машине:
ssh-keygen -t ed25519 -C "khamzat-clinika"
cat ~/.ssh/id_ed25519.pub  # пришли мне эту строку
```
Я добавлю в `/root/.ssh/authorized_keys`, затем заблокирую пароль.

### 2. Ротация секретов в `.env`
Все текущие секреты в публичном GitHub. Нужно:
- Сгенерить новый `SECRET_KEY` (`openssl rand -hex 32`)
- Сменить `JWT_SECRET`
- Получить новый `MIS_API_KEY` от Renovatio
- Сгенерить новый `TURN_SECRET` (32-байтный hex)
- Сменить `webhook_api_key`
- Запросить у бот-провайдеров (BotFather) ротацию `SUPPORT_BOT_SECRET`
- Сменить `SUPERADMIN_PASSWORD`

После — `docker compose down && docker compose up -d` (~10 мин downtime).

### 3. `git filter-repo` чистка истории
Удалить `.env` из всей истории git, чтобы публичный repo больше не содержал секретов.
```bash
pip install git-filter-repo
cd /opt/clinika
git filter-repo --path .env --invert-paths
git push --force-with-lease origin main
```
Все локальные клоны после этого нужно переклонить.

### 4. ENCRYPT_PASSPHRASE для бэкапов
```bash
ssh root@212.57.118.126 'cat > /etc/clinika-backup.env <<EOF
ENCRYPT_PASSPHRASE=<надёжный_пароль_30+_символов>
EOF
chmod 600 /etc/clinika-backup.env'
```
**Сохрани пароль в KeePass / 1Password!** Без него восстановление невозможно.

### 5. rclone для offsite
```bash
ssh root@212.57.118.126 'rclone config'
# n) New remote
# name: yandex
# storage: yandex
# Auto config? Yes (откроется браузер для OAuth)
```
Потом в `/etc/clinika-backup.env`:
```
RCLONE_REMOTE=yandex
RCLONE_PATH=clinika-backups
RCLONE_RETENTION_DAYS=90
```

### 6. Telegram-уведомления (опционально)
Добавить в `/etc/clinika-backup.env`:
```
TG_BOT_TOKEN=<токен бота>
TG_CHAT_ID=293633093
```
После бэкапа будет уведомление.

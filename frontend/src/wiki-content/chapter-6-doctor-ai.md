# Глава 6. Врач + AI

## Цель

Сделать так, чтобы врач за минуту до приёма понимал контекст пациента: историю, анализы, аллергии, риски. После приёма — за 30 секунд получал черновик плана лечения, который остаётся только подправить. Бизнес-смысл: сокращение времени на бумажную работу на 30-40%, рост качества протоколов, снижение врачебных ошибок.

## Что реализовано

- **Pre-visit briefing** — Gemini готовит краткое резюме пациента перед приёмом.
- **AI-генератор плана лечения** — после ввода диагноза предлагает план с дозировками и контролем.
- **Direct billing для visiting / partner врачей** — мгновенный расчёт после завершения приёма.
- **Голосовой ввод протокола** — Web Speech API в браузере, без отправки наружу.
- **Авто-кодирование МКБ-10** — AI подсказывает 3 наиболее вероятных кода по тексту протокола.

## Pre-visit briefing

За 5 минут до приёма (или при открытии карточки врачом) генерируется brief:

```
Иванов И.И., 47 лет
Хронические: артериальная гипертензия (с 2019), сахарный диабет 2 типа.
Аллергии: пенициллин (анафилаксия в 2021).
Предыдущий визит: 2026-04-15, доктор Алиев М.А., диагноз J06.9 (ОРВИ), назначен азитромицин.
Анализы за 90 дней: гликированный гемоглобин 7.2%, креатинин в норме.
Риск-индикаторы: пропустил последний контрольный приём (был назначен на 2026-04-30).
Возможный фокус сегодня: контроль терапии диабета, обсудить пропущенный приём.
```

## API endpoints

### Pre-visit briefing

```http
POST /doctor/ai/pre-visit
```

```json
{ "appointment_id": "..." }
```

Response:

```json
{
  "summary_md": "...",
  "highlights": ["allergy:penicillin", "missed_appointment", "diabetes_uncontrolled"],
  "generated_at": "2026-05-11T09:55:00Z",
  "ttl_minutes": 60
}
```

### План лечения

```http
POST /doctor/ai/treatment-plan
```

```json
{
  "patient_id": "...",
  "diagnosis_codes": ["J06.9"],
  "complaints": "Боль в горле, температура 38.5, кашель",
  "exam_findings": "Гиперемия задней стенки глотки, миндалины увеличены"
}
```

Response:

```json
{
  "plan_md": "Симптоматическая терапия...",
  "prescriptions": [
    { "name": "Парацетамол", "dose": "500 мг", "frequency": "при температуре >38.5", "duration_days": 5 }
  ],
  "follow_up_days": 3,
  "warnings": ["Пациент имеет аллергию на пенициллин — антибиотики только цефалоспориновой группы"]
}
```

### МКБ-10 подсказка

```http
POST /doctor/ai/icd10-suggest
```

```json
{ "text": "Острая боль в горле, температура, миндалины увеличены" }
```

Response:

```json
{
  "suggestions": [
    { "code": "J03.0", "name": "Стрептококковый тонзиллит", "confidence": 0.72 },
    { "code": "J06.9", "name": "Острая инфекция верхних дыхательных путей неуточнённая", "confidence": 0.58 },
    { "code": "J02.9", "name": "Острый фарингит неуточнённый", "confidence": 0.44 }
  ]
}
```

### Direct billing (visiting/partner)

```http
POST /visiting/appointments/{id}/complete
```

При завершении приёма:

1. Создаётся `appointment_outcome` (статус completed).
2. Расчёт суммы по контракту врача (price_per_visit или %).
3. Создаётся `BillingLedger` запись клиника→врач.
4. Если включено instant payout — `payout_request` в очередь.

## Где найти в UI

Кабинет doctor:

- **Расписание** — pre-visit briefing появляется как иконка-молния в карточке приёма.
- **Карточка приёма** — кнопки «Сгенерировать план», «МКБ-подсказка», «Диктовка».
- **Финансы** — для visiting/partner отдельная вкладка с прямым биллингом.

## Backend модели

| Таблица | Описание |
|---|---|
| `appointments` | основная сущность |
| `appointment_outcomes` | результат приёма (протокол, диагнозы, план) |
| `ai_pre_visit_briefs` | кеш briefings (TTL 60 мин) |
| `ai_treatment_plans` | сохранённые планы |
| `direct_billing_entries` | мгновенный биллинг для visiting/partner |

## Зависимости

- **Медкарта** (см. [концепт medcard](/wiki/concepts-medcard)) — источник истории.
- **Lab integrations** — анализы для briefing.
- **Бонусы** — direct billing создаёт записи bonus с пометкой `direct_billing=true`.

## Безопасность AI

- Все промпты к Gemini обезличиваются: ФИО → токены, телефон → маскируется.
- В audit log пишется хеш промпта (не сам промпт) для отслеживания.
- Пациент имеет право запросить запрет на AI-обработку (флаг `consent.ai_processing=false`).

## Настройки администратора

- `AI_PROVIDER` — `gemini` / `disabled`.
- `AI_PRE_VISIT_AUTO_GENERATE_MIN` — за сколько минут до приёма генерировать (default 5).
- `AI_TREATMENT_PLAN_REQUIRE_DIAGNOSIS` — требовать диагноз для генерации (default true).
- `DIRECT_BILLING_AUTO_PAYOUT` — авто-выплата instant (default false, нужен модуль).

## FAQ

**Можно ли отказаться от AI?** Да, во флагах профиля врача: `ai_features_enabled=false`. Кнопки исчезнут.

**Что делать если AI предложил неподходящий план?** Просто отредактировать перед сохранением. AI — черновик, не финальный документ.

**Brief не появился — что не так?** Проверьте AI_PROVIDER в настройках платформы. Если `disabled` — функция выключена.

**Direct billing — это законно?** Это внутренний расчёт клиника↔врач, не платёж пациента. Регулируется договором клиники с врачом и НК РФ.

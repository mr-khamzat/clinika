# Модуль «Здоровье+ (пациентские подписки)»

**1 990 ₽/мес · 21 500 ₽/год** · ключ `health_plus_module` · категория `patient_engagement` · popular = true · подключается в `/admin → Тарифы → Подключаемые модули`.

Месячные и годовые подписки для пациентов на пакеты услуг: безлимит чата с врачом, скидка на анализы, ежемесячная доставка витаминов, профилактические осмотры. Источник стабильного MRR для клиники.

## Что это даёт клинике

- Стабильный денежный поток: MRR подписок не зависит от посещений.
- Удержание пациентов: подписчик не уходит к конкурентам, потому что «уже оплачено».
- Семейные тарифы → растёт средний чек на семью.
- Аналитика churn и LTV — точно понятна экономика модели.

## Что это даёт пациенту

- Безлимитный чат с врачом без записи на приём.
- Скидка 15-30% на все услуги клиники.
- Подарочные сертификаты на ДР членов семьи.
- Ежемесячная доставка витаминов / БАД (опционально).
- Профилактический осмотр раз в год бесплатно.

## Что входит технически

- **Планы** (`PatientSubscriptionPlan`): несколько тарифов (Базовый / Семейный / Premium). С разными бенефитами.
- **Подписки** (`PatientSubscription`): связь пациент ↔ план, даты start/end, статус.
- **Бенефиты** (`SubscriptionBenefit`): что входит в каждый план (чат, скидка, осмотр).
- **Поставки** (`SubscriptionSupply`): ежемесячная отправка набора (витамины), cron генерирует заявку для регистратора.
- **Денежные операции**: автопродление через ЮKassa (если есть `recurring_payment_id`).
- **Module gating**: чат пациент-врач (`patient_chat`) доступен только подписчикам активного плана с бенефитом `unlimited_chat`.
- **Cash activation**: ручная активация регистратором (для оплаты наличкой / переводом без онлайна).

## Как настроить

1. Активировать модуль в `/admin → Тарифы → Подключаемые модули`.
2. `/admin/subscription-plans` — создать 2-3 тарифа:
   - **Базовый** 990 ₽/мес: чат + 10% скидка.
   - **Семейный** 1 990 ₽/мес: до 4 членов семьи + чат + 15% скидка.
   - **Premium** 2 990 ₽/мес: всё выше + витамины + осмотр.
3. Привязать бенефиты к каждому плану.
4. (Опционально) Cron-витамины: задать дату-якорь, через сколько дней после старта подписки отправлять «соберите комплект».

## Как пользоваться

### Со стороны пациента

1. В личном кабинете блок «Здоровье+» с тарифами.
2. Нажимает «Подключить» → редирект в ЮKassa или к регистратору (cash activation).
3. После активации — открывается чат с врачом, видна скидка на все услуги клиники.
4. Управление: пауза / отмена / смена тарифа в `/patient/subscription/my`.

### Со стороны клиники

- `/admin/subscriptions` — список активных подписок.
- `/admin/subscriptions/{id}` — детали, история платежей, использование бенефитов.
- Cash activation: `/admin/subscriptions/cash-activate` — для оплаты наличными.
- Аналитика: MRR, churn, ARPU, retention по когортам.

## API endpoints

- `GET /patient/subscription/plans` — публичные тарифы (без auth для маркетинга).
- `GET /patient/subscription/plans/{plan_key}/benefits-detail` — детали бенефитов.
- `POST /patient/subscription/inquire-details` — заявка на детальный просчёт (для лидов).
- `GET /patient/subscription/my` — моя подписка.
- `POST /patient/subscription/start` — начать подписку (после успешной оплаты).
- `POST /patient/subscription/cancel` — отменить.
- `POST /patient/subscription/resume` — возобновить.
- `GET /patient/subscription/benefits` — мои бенефиты.
- `POST /patient/subscription/supply/generate-now` — сгенерировать заявку на поставку (cron).

Admin:
- `GET /admin/subscription-plans` — управление тарифами.
- `POST /admin/subscription-plans` — создать тариф.
- `POST /manager/subscription/cash-activate` — cash activation от регистратора.

## Известные ограничения

- Семейный тариф — лимит участников жёсткий (4 человека), нельзя добавить 5-го.
- Cron витаминов — раз в месяц, нельзя настроить другую частоту в текущей версии.
- Возвраты денег за неиспользованные дни — пока вручную через ЮKassa.
- Только один активный план на пациента (нельзя складывать Базовый + Premium).

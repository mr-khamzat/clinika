# Модуль «Телемедицина»

**4 990 ₽/мес** · модуль `telemedicine` · подключается в `Тарифы → Подключаемые модули`

Видеоприём врач ↔ пациент через WebRTC без сторонних провайдеров. Работает прямо в браузере (на стороне врача — ваш CRM, на стороне пациента — мобильный браузер по одноразовой ссылке).

## Как это работает

1. Врач в карточке пациента нажимает **«Видеоприём»** — создаётся `TelemedicineSession`.
2. Пациенту автоматически отправляется SMS / Telegram-сообщение с одноразовой ссылкой на `/p/telemed/<token>`.
3. По переходу — браузер просит доступ к камере и микрофону, ICE-конфиг отдаётся через `/presence/ice-config` (HMAC-SHA1 REST).
4. P2P-канал устанавливается через ваш собственный coturn-сервер (TURN/STUN), без третьих сторон. Сигналинг — по WebSocket `/presence/ws`.

## Что входит

- Видео + аудио высокого качества, до 720p
- Текстовый чат рядом с видео (`TelemedicineChatMessage`)
- Электронные назначения врача (`TelemedicinePrescription`) — пациент видит сразу
- История всех сессий по пациенту
- Statuses: `waiting → active → ended → cancelled`
- Длительность фиксируется автоматически

## Ограничения

- 1:1 (врач + пациент). Multi-party конференции на 3+ участников — отдельный модуль `video_conference` (4490 ₽/мес).
- Запись приёма — отдельный модуль `call_recording` (3990 ₽/мес, включает Whisper-транскрипцию).
- Скачивать медиа на устройство пациента нельзя (только просмотр в браузере).

## Когда подключать

Если у вас есть пациенты, которые редко или удалённо проживают, или вы хотите сократить очереди в клинике на повторные приёмы (контроль анализов, корректировка терапии, психология).

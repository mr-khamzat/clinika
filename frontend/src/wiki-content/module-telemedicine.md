# Модуль «Телемедицина»

**4 990 ₽/мес · 53 892 ₽/год** · ключ `telemedicine` · категория `telemedicine` · подключается в `/admin → Тарифы → Подключаемые модули` (14 дней триал).

Видеоприём врач ↔ пациент через WebRTC без сторонних провайдеров. Работает прямо в браузере: на стороне врача — ваш кабинет CRM, на стороне пациента — мобильный или десктоп-браузер по одноразовой ссылке. Никаких сторонних API, медиа-стримов через ваши TURN-серверы.

## Что это даёт клинике

- Снижение очередей в клинике на повторные приёмы (контроль анализов, корректировка терапии, психотерапия).
- Расширение географии пациентов: доктор в одной клинике обслуживает пациента из другой.
- Сокращение no-show: пациент не пропустит приём «потому что не доехал».
- Юридически валидный приём с фиксацией в ЭМК (диагноз, протокол, назначения).

## Что входит технически

- Видео + аудио до 720p, peer-to-peer через WebRTC.
- Текстовый чат рядом с видео (`TelemedicineChatMessage`) на случай слабой связи.
- Электронные назначения (`TelemedicinePrescription`) — пациент видит сразу в личном кабинете.
- Статусы сессии: `waiting → active → ended → cancelled`. Длительность фиксируется автоматически.
- История всех сессий по пациенту в его медкарте.
- Сигналинг через WebSocket `/presence/ws/{token}` и `/presence/ws/doctor/{session_id}`.
- ICE-конфиг `/presence/ice-config` — HMAC-SHA1 REST credentials (ephemeral, TTL 1ч).
- Собственный coturn на 3478/udp для TURN/STUN (без зависимости от Google STUN).

## Как настроить

1. Перейти в `/admin → Тарифы → Подключаемые модули`.
2. Найти карточку «Телемедицина» (4 990 ₽/мес). Нажать «Активировать триал» или «Подписаться».
3. (Опционально) В `tenant_module_subscriptions.config` задать `max_session_minutes` (по умолчанию 60).
4. Убедиться, что у врача в карточке указана роль `doctor` и активный профиль.
5. У пациента должен быть подтверждённый телефон или Telegram для отправки одноразовой ссылки.

## Как пользоваться

### Сценарий со стороны врача

1. В календаре врача создаётся приём с типом `telemedicine`.
2. В назначенное время врач нажимает «Начать видеоприём» в карточке приёма.
3. Открывается окно врача, ожидает подключения пациента (статус `waiting`).
4. После подключения — обычная видеоконсультация. Все назначения и протокол вносятся в карточку прямо во время сессии.
5. По кнопке «Завершить приём» — статус `ended`, длительность фиксируется, всё попадает в медкарту.

### Сценарий со стороны пациента

1. Пациент получает SMS / Telegram-сообщение с одноразовой ссылкой `/p/telemed/<token>`.
2. Переходит по ссылке, браузер запрашивает доступ к камере и микрофону.
3. Появляется кнопка «Войти в приём» — переходит в комнату.
4. После завершения видит сводку: диагноз, рекомендации, назначения, ссылку на оплату (если нужно).

## API endpoints

- `POST /telemedicine/sessions` — создать сессию (доктор).
- `GET /telemedicine/sessions` — список сессий тенанта (требует модуль активен).
- `GET /telemedicine/sessions/{id}` — детали сессии.
- `POST /telemedicine/sessions/{id}/start` — стартовать (waiting → active).
- `POST /telemedicine/sessions/{id}/end` — завершить (active → ended).
- `POST /telemedicine/sessions/{id}/chat` — отправить chat-message.
- `POST /telemedicine/sessions/{id}/prescriptions` — добавить назначение.
- `WS /presence/ws/{token}` — сигналинг WebRTC, пациент.
- `WS /presence/ws/doctor/{session_id}` — сигналинг, доктор.
- `GET /presence/ice-config` — ephemeral TURN-credentials (HMAC-SHA1 REST).

## Известные ограничения

- 1:1 только (врач + пациент). Multi-party конференции на 3+ участников — отдельный модуль `video_conference` (4 490 ₽/мес).
- Запись приёма — отдельный модуль `call_recording` (3 990 ₽/мес, включает AI-транскрипция-транскрипцию).
- Скачивать медиа на устройство пациента нельзя (только просмотр в браузере).
- TURN-сервер — один экземпляр на платформу. При высокой нагрузке (>50 параллельных сессий) понадобится кластер coturn.

## Метрики качества

- **MOS** (Mean Opinion Score) — пациент после сессии оценивает связь 1-5.
- **Connection time** — время от перехода по ссылке до старта медиа.
- **Disconnect rate** — % сессий, прерванных раньше плановой длительности.
- **Bitrate** — middle 480p / good 720p. Логируется в `TelemedicineSession.metrics_json`.

## Best practices

1. Перед первым приёмом — отправить пациенту инструкцию (картинка-памятка): где разрешить камеру/микрофон.
2. Свет на лицо доктора, не сзади (избегать силуэта).
3. Гарнитура у доктора (микрофон ближе ко рту → лучше AI-транскрипция при записи).
4. Контрольный 5-минутный тест-приём с новым пациентом перед первой полноценной консультацией.

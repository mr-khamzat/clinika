# StaffChat · Каналы и личные сообщения

Внутренний чат сотрудников КлиникСеть с тремя типами комнат: direct, group, channel. По духу — Slack/Mattermost, но привязанный к ролям, клиникам и франшизе.

## Зачем это нужно

Раньше сотрудники общались в Telegram/WhatsApp — это:

- утекало через личные устройства;
- терялось при увольнении;
- не имело привязки к пациентам, сменам, кейсам;
- не подчинялось 152-ФЗ.

StaffChat закрывает это: чат внутри CRM, RBAC, файлы до 50 МБ, авто-удаление через 48 ч (можно настроить), журнал событий.

## Три типа комнат (rooms)

| Тип | Назначение | Кто видит |
|-----|-----------|-----------|
| `direct` | 1-на-1 переписка | только два участника |
| `group` | закрытая группа по приглашениям | приглашённые |
| `channel` | публичный канал клиники/франшизы | все, кто состоит или нашёл в каталоге |

Все типы хранятся в одной таблице `staff_chat_rooms`, различаются по полю `type`.

## Как создать канал

```bash
POST /api/staff-chat/channels
Authorization: Bearer <token>
{
  "name": "registratura-feedback",
  "description": "Обратная связь от регистраторов",
  "type": "channel",
  "is_public": true
}
```

В UI: Sidebar → «+ Создать канал». Имя автоматически приводится к `kebab-case`. После создания владелец канала может приглашать через `POST /api/staff-chat/channels/{id}/invite`.

## Каталог публичных каналов

`/staff-chat/channels/public` — список всех публичных каналов с фильтром по клинике и количеству участников. Сотрудник нажимает «Войти» → `POST /api/staff-chat/channels/{id}/join`.

## Покинуть канал

Кнопка «Покинуть» в шапке канала → `POST /api/staff-chat/channels/{id}/leave`. Если уходит последний участник публичного канала, канал помечается архивным через 7 дней.

## Sidebar UI

Левая колонка разбита на две секции:

```
┌─ Каналы ─────────────────┐
│ # general                │  ← публичный
│ # registratura-feedback  │
│ 🔒 management            │  ← приватный group
└──────────────────────────┘
┌─ Direct messages ────────┐
│ 👤 Иванов И. И.   ●     │  ← unread badge
│ 👤 Петрова А. С.        │
└──────────────────────────┘
```

Иконки: `#` для channel, `🔒` для group, `👤` для direct.

## RBAC

- `super_admin` — видит все каналы своего тенанта.
- `franchise_owner` / `manager` — может создавать public-каналы.
- Остальные роли — только direct + group, в которых их пригласили.

## Команды и API

- `GET    /api/staff-chat/channels` — мои комнаты
- `GET    /api/staff-chat/channels/public` — каталог
- `POST   /api/staff-chat/channels` — создать
- `POST   /api/staff-chat/channels/{id}/invite` — пригласить
- `POST   /api/staff-chat/channels/{id}/join` — войти
- `POST   /api/staff-chat/channels/{id}/leave` — выйти

## FAQ

**Может ли регистратор писать управляющему напрямую?** Да, direct-чат разрешён между любыми двумя сотрудниками клиники.

**Хранятся ли сообщения после увольнения?** Сообщения остаются, но автор отображается как «Бывший сотрудник».

**Есть ли мобильная версия?** Открывается в браузере мобильного; нативное приложение — в roadmap.

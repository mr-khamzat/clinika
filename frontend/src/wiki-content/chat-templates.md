# Шаблоны быстрых ответов в чате

Готовые тексты ответов для регистратуры. Печатаются за один символ — `/` в поле ввода открывает список с автокомплитом.

## Зачем это нужно

90% сообщений регистратора — повторяющиеся: «Здравствуйте, на какое время вам удобно?», «Адрес клиники: …», «Перезвоним в течение 10 минут». Шаблоны:

- ускоряют ответы в 3-5 раз;
- унифицируют коммуникацию (одинаковая вежливость у всех регистраторов);
- снижают опечатки в адресах, телефонах, цене услуг;
- считают популярность (`usage_count`) — видно, что чаще всего нужно.

## Как работает

В БД таблица `chat_templates`:

| Поле | Описание |
|------|----------|
| `id` | UUID |
| `tenant_id` | принадлежит франшизе |
| `owner_id` | автор; NULL = общий шаблон |
| `shortcut` | короткое имя, например `здр` |
| `body` | текст с плейсхолдерами |
| `usage_count` | счётчик |
| `is_public` | True = виден всей клинике |

UI имеет два режима:

1. **CRUD-страница** `/manager/chat-templates` — создавать, редактировать, удалять, помечать публичными.
2. **Автокомплит в чате**: в `textarea` чата клиники при наборе `/` открывается popup с фильтром по shortcut и body. Сортировка — по `usage_count DESC`.

Плейсхолдеры:

- `{patient_name}` — имя пациента из треда;
- `{clinic_name}` — название клиники;
- `{address}` — адрес;
- `{date}` — текущая дата.

Backend подставляет их при отправке.

## Как настроить

1. `/manager/chat-templates` → «Создать шаблон».
2. Заполнить:
   - shortcut: `здр`
   - body: `Здравствуйте, {patient_name}! Спасибо за обращение в {clinic_name}. На какое время вам удобно записаться?`
3. Поставить галочку «Общий» (`is_public = true`), если шаблон для всех регистраторов.
4. Сохранить.
5. В чате: ввести `/здр` → Enter → текст подставится с подставленным именем пациента.

## Команды и API

- `GET    /api/chat/templates` — список (свои + публичные)
- `POST   /api/chat/templates` — создать
- `PATCH  /api/chat/templates/{id}` — обновить
- `DELETE /api/chat/templates/{id}` — удалить
- `POST   /api/chat/templates/{id}/use` — инкремент `usage_count`

## Личные vs общие

- **Личные** (owner_id = текущий пользователь) — только автор видит.
- **Общие** (is_public = true, требует роли `manager`+) — видят все в клинике.

Регистратор может пометить личный шаблон как общий только через управляющего.

## FAQ

**Сколько шаблонов рекомендуется?** 15-25 штук. Больше — теряется польза, autocomplete становится шумным.

**Можно ли вложения в шаблоне?** Пока нет — только текст. Файлы передаются drag&drop напрямую.

**Поддерживается ли markdown?** Базовый: **жирный**, *курсив*, ссылки. Без таблиц.

# Модуль «Loyalty Pro»

**2 990 ₽/мес** · модуль `loyalty_pro` · подключается в `Тарифы → Подключаемые модули`

Полная программа лояльности: тиры, акции, начисление баллов, обмен на услуги, реферальные бонусы. Базовые бонусы за направления (`Bonus`) есть бесплатно — этот модуль расширяет их в полноценную loyalty.

## Что входит сверх базовых бонусов

- **Тиры** (`LoyaltyTier`): бронза/серебро/золото/платина. Автоповышение по сумме платежей за период.
- **Транзакции** (`LoyaltyTransaction`): детальная история начислений и списаний баллов.
- **Акции** (`LoyaltyRule`): «1 балл за каждые 100₽», «2× за визиты в день рождения», «приведи друга — 500 баллов», «отзыв на Яндекс — 200 баллов».
- **Каталог наград** (`LoyaltyReward`): на что можно потратить баллы — скидка на услугу, бесплатная диагностика, мерч клиники, абонемент.
- **Тиры → бонусы**: для платины автоматически 10% скидка везде.

## UI

- В кабинете пациента — баланс, история, доступные награды, прогноз до следующего тира.
- В админке — настройка правил, аналитика (LTV по тирам).

## Реферальная система

- Каждый пациент получает реферальный QR.
- При первом визите по этому QR — баллы тому кто привёл + новому пациенту.

## Когда подключать

Если у вас сеть с месячной выручкой от 1 млн ₽. Loyalty повышает retention на 15-25% по нашим данным.

## Зависимость

- Базовые бонусы (`Bonus`) работают независимо
- Для рассылок об акциях нужен модуль [SMS-маркетинг](module-sms-marketing.md)

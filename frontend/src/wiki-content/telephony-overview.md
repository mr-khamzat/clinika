# PSTN-телефония — обзор

Интеграция КлиникСеть с городскими номерами и облачными АТС. Позволяет регистратору принимать и совершать обычные телефонные звонки прямо из CRM, фиксировать их в карте пациента и связывать с записями на приём.

## Зачем это нужно

До PSTN-модуля у клиник был только внутренний софтфон Calls — он работает между сотрудниками сети. Но пациенты звонят с обычных мобильных и городских номеров. PSTN-модуль закрывает эту дыру:

- Регистратор видит входящий звонок с подсказкой «Пациент Иванов И. И., запись на 14:30».
- Каждый звонок автоматически связывается с пациентом по номеру.
- Записи разговоров (если включено у провайдера) подтягиваются и доступны управляющему.
- KPI регистратуры (пропущенные, среднее время ответа) считаются автоматически.

## Как работает

Под капотом — три модели в БД:

| Модель | Назначение |
|--------|-----------|
| `TelephonyConfig` | Учётка провайдера (Sipuni / Mango / Zadarma): креды, статус, webhook secret |
| `DidNumber` | Городской номер, привязанный к клинике (несколько на клинику) |
| `PhoneCall` | Журнал звонков: `direction`, `from`, `to`, `started_at`, `duration`, `recording_url`, `patient_id` |

Поток входящего звонка:

```
1. Пациент звонит на DID-номер клиники
2. Провайдер шлёт webhook → /api/telephony/webhook/<provider>
3. Backend: верифицирует подпись, создаёт PhoneCall(status=ringing)
4. WebSocket-push регистратору с поп-апом «Входящий»
5. После завершения провайдер шлёт второй webhook → status=ended + duration
```

Поддерживаются три провайдера — Sipuni, Mango Office, Zadarma. У каждого свой адаптер в `app/services/telephony/`.

## Как настроить

1. Войти как `manager` или `franchise_owner`.
2. Перейти `/manager/telephony` → «Подключить провайдера».
3. Выбрать провайдера из выпадающего списка, ввести креды (детали — в статьях про каждого провайдера).
4. Нажать «Проверить соединение» — backend сделает тестовый API-запрос.
5. Скопировать webhook URL и вставить его в личный кабинет провайдера.
6. Привязать DID-номера к клиникам в разделе «Номера».

> 💡 Совет: начните с одного тестового номера. После 10 успешных звонков подключайте остальные.

## Команды и API

- `GET  /api/telephony/configs` — список подключений
- `POST /api/telephony/configs` — создать
- `POST /api/telephony/test/{id}` — проверить креды
- `GET  /api/telephony/calls?clinic_id=X&from=...&to=...` — журнал звонков
- `POST /api/telephony/webhook/{provider}` — приём событий (публичный, с HMAC-проверкой)

## FAQ

**Можно подключить несколько провайдеров одновременно?** Да, у каждой клиники свой `TelephonyConfig`.

**Что с шифрованием записей?** Записи лежат у провайдера, КлиникСеть хранит только signed URL.

**Считаются ли минуты как платный модуль?** PSTN-модуль входит в тариф «Бизнес» и выше. Биллинг по факту звонков ведёт провайдер.

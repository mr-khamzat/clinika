# О платформе КлиникСеть

## Что такое КлиникСеть

КлиникСеть — это многотенантная SaaS-платформа для управления сетью медицинских клиник в формате франшизы. Каждый владелец франшизы получает изолированное пространство для своих клиник, врачей, пациентов и финансов, а платформа берёт на себя инфраструктуру, биллинг, безопасность, интеграции и развитие функций.

В отличие от классической МИС, КлиникСеть строится вокруг трёх идей:

- **Франшиза как первоклассный объект.** Владелец сети управляет несколькими клиниками, общим брендом, единым каталогом услуг, лояльностью и аналитикой по всей сети.
- **Marketplace модулей.** Базовая подписка покрывает приём пациентов и направления. Всё остальное — телемедицина, AI, лояльность, реклама, лаборатории — подключается отдельно и оплачивается по подписке.
- **Самостоятельный запуск.** Новая франшиза проходит онбординг за 15 минут через wizard и получает 14 дней триала без оплаты.

## Зачем платформа существует

Российский медицинский рынок исторически держится на закрытых МИС, которые продаются как коробка, требуют интегратора и не поддерживают мультиклинические сценарии. Платформа решает четыре боли:

1. **Высокий порог входа.** Стандартная МИС стоит 200-500 тысяч на запуск, требует серверов на стороне клиники и команды поддержки. КлиникСеть запускается за час и оплачивается помесячно.
2. **Изолированные клиники.** Когда у предпринимателя 2-3 клиники под одним брендом, классическая МИС не даёт ни сводной аналитики, ни маршрутизации пациентов между точками. Платформа делает это из коробки.
3. **Слабая монетизация рекомендаций.** Внешние врачи приводят пациентов «в чёрную», без учёта и без бонуса. КлиникСеть даёт легальный механизм: направление → подтверждение → бонус по налоговой модели партнёра.
4. **Дорогие интеграции.** Подключить ЮKassa, ОФД, лабораторию или Telegram-уведомления в классической МИС — отдельный проект на месяцы. У платформы это готовый модуль за пару кликов.

## Для кого

| Сегмент | Чем полезна платформа |
|---|---|
| Одиночная клиника, 1 точка | Базовый тариф, запись пациентов, медкарта, направления |
| Сеть 2-10 клиник | Multi-clinic view, общий каталог, межклиникальные направления |
| Франшизный оператор | White-label, региональный контроль, аналитика по сети, единая лояльность |
| Внешние врачи / партнёры | Личный кабинет, направления, бонусы, налоговая прозрачность |
| Агрегаторы (СберЗдоровье, Здоров.онлайн) | Партнёрская программа, API v1, webhook-уведомления |

## Что входит в базовый тариф

- Запись пациентов и расписание врачей
- Медкарта-timeline и направления
- Кабинеты для всех 11 ролей
- Многоклиничная маршрутизация
- Семейный профиль пациента
- Уведомления (email + Telegram бесплатно)
- Базовая аналитика клиники
- Резервное копирование БД
- Поддержка через тикеты

## Что подключается как модуль

См. [Каталог платных модулей](/wiki/concepts-modules). Самые востребованные:

- Программа лояльности Pro (2 990 ₽/мес)
- SMS-маркетинг (1 990 ₽/мес)
- Здоровье+ (подписка пациента, доход клиники)

## Чем отличается от конкурентов

| Параметр | Классическая МИС | КлиникСеть |
|---|---|---|
| Запуск | Недели-месяцы | 15 минут |
| Серверы | На стороне клиники | SaaS, 100% облако |
| Multi-clinic | Расширение | В ядре |
| Marketplace | Нет | 20+ модулей |
| API | Закрытый | Public API v1 |
| White-label | Дорогая опция | Один клик |
| Тарифы | Лицензия + поддержка | Подписка по тенанту + модулям |

## Версии и тарифы

Платформа имеет три тарифных плана:

- **Basic** — до 3 клиник, 20 пользователей, 500 направлений/мес.
- **Professional** — до 10 клиник, 100 пользователей, 5000 направлений/мес.
- **Enterprise** — без жёстких лимитов, кастомные SLA, выделенный менеджер.

Каждый тариф добавляет квоты на API-запросы, размер хранилища документов и приоритет в поддержке. Все модули доступны на всех тарифах — подключение по отдельной подписке.

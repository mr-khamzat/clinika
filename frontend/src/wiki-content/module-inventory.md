# Модуль «Inventory»

**1 990 ₽/мес** · модуль `inventory` · подключается в `Тарифы → Подключаемые модули`

Учёт расходных материалов, оборудования, остатков и движений. Алерты по низким остаткам.

## Что входит

- **Каталог** (`InventoryItem`): артикул, наименование, единица измерения, минимальный остаток, поставщик.
- **Категории** (`InventoryCategory`): шприцы, перевязка, реактивы, бытовая химия, оборудование и т.п.
- **Остатки на клинику** (`InventoryStock`): сколько чего где.
- **Движения** (`InventoryMovement`): приход (закупка), расход (списание на приём), перемещение между клиниками, инвентаризация (корректировка).
- **Алерты**: при остатке ниже минимума — уведомление управляющему клиники.
- **Отчёты**: расход по периодам, ABC-анализ, прогноз закупок.

## Интеграция с приёмами

При создании протокола приёма врач выбирает использованные расходники → автоматически создаётся `InventoryMovement` с типом `consumption`. Остаток уменьшается.

## Заказ поставщику

В настройке элемента — поставщик и срок поставки. При достижении минимального остатка генерируется черновик заказа (просто PDF с шапкой и списком позиций — без интеграции с поставщиком напрямую).

## Когда подключать

При сети из 2+ клиник. Помогает понять реальные расходы на материалы, выявить избыточные закупки и потери.

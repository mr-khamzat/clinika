# PSTN-провайдер · Sipuni

Подключение Sipuni — российской облачной АТС с офисами в РФ. Это самый «дружелюбный» провайдер: callback-режим, простые webhooks, российские реквизиты.

## Зачем именно Sipuni

- Серверы в РФ — нет вопросов по 152-ФЗ.
- Callback-режим: чтобы соединить регистратора с пациентом, Sipuni сначала звонит регистратору, потом набирает пациента — экономит трафик на стороне сотрудника.
- Записи разговоров хранятся 90 дней бесплатно.
- Бесплатные минуты внутри Sipuni.

## Как получить креды

1. Зарегистрировать аккаунт на https://sipuni.com.
2. В личном кабинете: «Интеграции» → «API» → создать новый ключ.
3. Скопировать:
   - `sipuni_id` (10 цифр) — идентификатор аккаунта;
   - `secret_key` (32 символа) — для подписи запросов.

## Как настроить в КлиникСеть

1. Открыть `/manager/telephony` → «Подключить провайдера» → Sipuni.
2. Ввести `sipuni_id` и `secret_key`.
3. Сохранить — система покажет webhook URL:

   ```
   https://клиниксеть.рф/api/telephony/webhook/sipuni
   ```

4. В Sipuni: «Настройки» → «Webhook URL» → вставить адрес.
5. В Sipuni включить события: `call.start`, `call.end`, `call.record_ready`.
6. Привязать DID-номера к клиникам.

## Callback-режим (исходящие)

При нажатии «Позвонить» в карточке пациента:

```
1. CRM → POST https://sipuni.com/api/callback/call?…
2. Sipuni звонит на внутренний SIP регистратора
3. Регистратор поднимает трубку
4. Sipuni набирает номер пациента
5. Звонок соединён
```

Параметр `phone` в POST — номер пациента, `ringTone` — мелодия гудка, `sipnumber` — внутренний SIP регистратора (берётся из его профиля).

## Подпись webhook

```python
import hashlib
expected = hashlib.md5(f"{secret_key}+{caller}+{called}+{call_id}".encode()).hexdigest()
```

Backend сверяет `request.headers["X-Sipuni-Sign"]` с `expected` — иначе 401.

## FAQ

**Sipuni поддерживает SMS?** Да, но через отдельный модуль `setup-sms`. PSTN-модуль отвечает только за голос.

**Как часто Sipuni шлёт callback?** Один webhook на старте звонка, один на завершении, один на готовности записи (через 2-5 минут).

**Можно ли несколько DID на один аккаунт?** Да, количество DID ограничено только тарифом Sipuni.

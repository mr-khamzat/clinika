# Calls 1.0.30 · Новые возможности

Релиз десктопного приложения КлиникСеть Calls 1.0.30 (Electron). Главные фишки: глобальные горячие клавиши, темы оформления с persist, badge непрочитанных в трее, PSTN-диалпад с буквами на цифрах.

## Зачем апгрейдиться

- Регистратор без открытого окна Calls может одной комбинацией заглушить микрофон во время разговора с пациентом в кабинете.
- Тёмная тема снижает усталость глаз при ночных сменах.
- Badge в трее сразу показывает «есть 3 пропущенных» — не нужно держать окно открытым.
- Диалпад для PSTN-звонков — можно набирать номер тоновым набором (для IVR провайдеров).

## Глобальные горячие клавиши

Регистрируются через `globalShortcut.register()` в `main.js`. Работают, даже когда Calls свёрнут в трей:

| Сочетание | Действие |
|-----------|---------|
| `Ctrl+Shift+M` | Toggle микрофона |
| `Ctrl+Shift+L` | Toggle динамика (mute speaker) |
| `Ctrl+Shift+H` | Поднять/повесить трубку |

На macOS `Ctrl` заменяется на `Cmd`. Сочетания настраиваются в Настройки → Горячие клавиши (rebind через `globalShortcut.unregister()` + регистрация нового).

> ⚠ Если другое приложение уже захватило сочетание, `globalShortcut.register` вернёт false — Calls покажет предупреждение «Не удалось зарегистрировать. Освободите сочетание или выберите другое».

## Темы оформления

Три режима:

- `system` — следует за `nativeTheme.shouldUseDarkColors`;
- `light` — всегда светлая;
- `dark` — всегда тёмная.

Выбор сохраняется в `userData/theme.json`:

```json
{ "mode": "dark", "saved_at": "2026-05-17T08:00:00Z" }
```

При запуске `main.js` читает файл и через IPC шлёт renderer'у `theme:set`. Renderer переключает CSS-переменные (`--bg`, `--fg`, `--accent`).

Переключение «на лету» — без перезапуска приложения.

## Tray badge с unread counter

`tray.setImage()` рисует число непрочитанных поверх иконки. На macOS используется `app.dock.setBadge(String(unread))`, на Windows и Linux — собственный канвас.

```jsx
// renderer/store/notifications.js
useEffect(() => {
  window.electron.tray.setBadge(unreadCount);
}, [unreadCount]);
```

При `unreadCount === 0` badge скрывается. При клике по треее окно разворачивается и фокусируется на канале с непрочитанным.

## PSTN-диалпад

Появляется только если у пользователя подключён модуль PSTN-телефонии. Кнопки 0-9, *, # с подписями букв как на классическом телефоне:

```
┌─────┬─────┬─────┐
│  1  │  2  │  3  │
│     │ ABC │ DEF │
├─────┼─────┼─────┤
│  4  │  5  │  6  │
│ GHI │ JKL │ MNO │
├─────┼─────┼─────┤
│  7  │  8  │  9  │
│ PQRS│ TUV │WXYZ │
├─────┼─────┼─────┤
│  *  │  0  │  #  │
│     │  +  │     │
└─────┴─────┴─────┘
```

При активном звонке нажатие отправляет DTMF-тон через `RTCDTMFSender.insertDTMF(digit)`. До соединения — формирует номер для исходящего вызова.

Долгое нажатие на `0` вводит `+` (для международных номеров).

## Auto-update

`electron-updater` проверяет обновления при старте и каждые 4 часа. Канал `latest`:

```
https://updates.клиниксеть.рф/calls/latest.yml
```

Если найдена новая версия — silent download → уведомление «Готово к установке, перезапустить?». При согласии — `autoUpdater.quitAndInstall()`.

Для отката — переменная `CALLS_UPDATE_CHANNEL=beta` в env запуска.

## Команды

```bash
# Локальная сборка
cd /opt/clinikset-calls
npm install
npm run build:win  # → dist/КлиникСеть Calls Setup 1.0.30.exe
npm run build:mac  # → dist/КлиникСеть Calls-1.0.30.dmg
```

Подписи кода нет (ожидается Apple Developer + EV-Win cert после выхода на рынок). Пользователи получают предупреждения SmartScreen/Gatekeeper — обходятся вручную.

## FAQ

**Старая версия 1.0.29 продолжит работать?** Да, до конца года. Затем будет принудительный апгрейд через auto-update.

**Можно ли отключить глобальные хоткеи?** Да, в Настройках → Горячие клавиши → «Отключить все».

**Где логи?** `userData/logs/calls.log`. На Windows: `%APPDATA%/КлиникСеть Calls/logs/`.

# Создание сотрудников

## Кому это руководство

Для **владельца франшизы** или **управляющего клиники**, который добавляет нового сотрудника в систему. Это пошаговая инструкция по приглашению, регистрации и активации сотрудника.

## Роли в системе

Перед приглашением определи роль:

| Роль | Когда использовать |
|---|---|
| `manager` | Управляющий клиники |
| `doctor` | Штатный врач клиники |
| `visiting_doctor` | Врач, работающий в нескольких клиниках сети |
| `partner_doctor` | Внешний врач, направляющий пациентов |
| `admin` (UI: «Регистратор») | Сотрудник фронт-офиса |
| `nurse` | Медсестра |
| `recruiter` | Рекрутер врачей |

Подробности — в соответствующих [статьях по ролям](/wiki).

## Шаг 1: создать invite-ссылку

В кабинете владельца / управляющего:

1. Раздел «Сотрудники» → «Пригласить».
2. Заполни форму:
   - **Имя сотрудника** (для приветствия в письме).
   - **E-mail или телефон** — куда отправить ссылку.
   - **Роль** — из списка выше.
   - **Клиника** — к какой привязать (для `doctor`, `nurse`, `admin`, `manager`).
   - **Специальности** — для врачей.
   - **Условия выплат** — процент, ставка (для врачей и партнёров).
3. Сохрани — система создаст приглашение.
4. Ссылка автоматически отправится на e-mail. Можно также скопировать и отправить в мессенджер.

## Шаг 2: регистрация по ссылке

Сотрудник:

1. Открывает ссылку (формат `/<slug>/invite/<code>`).
2. Видит карточку приглашения с указанной ролью.
3. Заполняет: имя, фамилию, телефон, пароль (для логина).
4. Соглашается с условиями.
5. Жмёт «Зарегистрироваться».

После регистрации профиль создаётся, но статус — **«Ожидает активации»**.

## Шаг 3: загрузка документов (для врачей)

Для ролей `doctor`, `visiting_doctor`, `partner_doctor` после регистрации требуется загрузить:

- Диплом о медицинском образовании.
- Сертификаты по специальностям.
- Документ, подтверждающий действующее право на работу (лицензия, ординатура).

В кабинете врача → «Профиль» → «Документы» → «Загрузить». Допустимые форматы — PDF, JPG, PNG.

## Шаг 4: проверка и активация

Управляющий / владелец видит уведомление о новом ожидающем активации сотруднике:

1. «Сотрудники» → фильтр «Ожидают активации».
2. Открой профиль, проверь данные и документы.
3. Если что-то не так — «Запросить доработку» с комментарием.
4. Если ОК — «Активировать».

После активации сотрудник может полноценно входить в свой кабинет.

## Шаг 5: настройка расписания (для врачей)

Сразу после активации:

1. «Расписание» → выбери нового врача.
2. Применить шаблон или задать вручную.
3. Слоты появятся для записи пациентов.

## Управление существующими сотрудниками

В разделе «Сотрудники» доступны действия:

- **Приостановить** — временно лишить доступа (например, отпуск). Расписание сохраняется.
- **Уволить** — деактивировать с указанием даты. Все будущие записи переносятся.
- **Сменить роль** — например, из регистратора в управляющего (требует подтверждения владельца).
- **Изменить условия** — процент / ставка для врача.
- **Сбросить пароль** — отправить ссылку на восстановление.

## Что делать, если invite не сработал

Возможные причины:

- E-mail попал в спам — проверь папку «Спам».
- Ссылка истекла (по умолчанию 14 дней) — пересоздай в кабинете.
- Сотрудник зашёл с другого устройства — invite привязан к устройству только при специальной настройке.

## Безопасность

> Внимание: каждое invite-приглашение содержит уникальный одноразовый токен. После регистрации токен инвалидируется. Не пересылай ссылку через незащищённые каналы — используй мессенджеры с E2E-шифрованием.

При увольнении сотрудника **обязательно** деактивируй учётку в тот же день. Иначе он сохранит доступ к данным клиники.
